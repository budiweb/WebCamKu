# Troubleshooting

- `JAVA_HOME is not set`: install JDK 17 and point `JAVA_HOME` to it.
- Android SDK not found: set `ANDROID_HOME` or add the untracked `android/local.properties` file described in [android.md](android.md).
- Missing Android platform: install Platform 35 and Build Tools 35.0.0 with Android Studio's SDK Manager.
- `dotnet` not found: install the .NET 10 SDK and open a new terminal.
- WPF cannot launch: run on Windows; WPF is Windows-only.
